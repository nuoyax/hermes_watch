# 视图说明

每个窗格渲染一种视图。窗格各自持有视图类型、相机状态与目标卫星，
因此可以一个窗格看地球、另一个窗格同时看地面轨迹。

## 视图类型

`ViewKind` 共 5 个变体，定义于 `ui/panes.rs`：

### 🌐 3D 地球

主视图。渲染内容：

- 深色太空背景，地球边缘带蓝色大气光晕；
- GPU 贴图地球球体 —— egui 三角网格，48 条纬带 × 96 条经带
  （约 4.8k 顶点 / 9.4k 三角面），逐顶点等距圆柱 UV，
  并按真实日下点做 Lambert 昼夜明暗；
- 3D 卫星标记，以及选中卫星的**真实 ECI 轨道椭圆**
  （白色绘制，转到地球背面时被遮挡，高度夸张 ×0.4 以便低轨也能看清）；
- 选中卫星的航天器模型。

**交互：** 拖拽旋转相机（水平位移改变偏航，俯仰限制在 ±1.5 rad），滚轮缩放
（缩放范围 40–500）。手动拖拽会解除位置锁定。拖拽结束 5 秒后，
相机平滑滑回朝向太阳的视角。俯仰缓动每帧 `k = 0.06`（约 0.7 秒），
自动复位滑行 `k = 0.03`（约 2 秒）。

**跟随锁定：** 时区快捷按钮可把相机锁定到某个地点，地球在其下自转。
锁定点由十字准星与标签标出。由于锁定锚定在地固坐标上，
解锁时会从相机**实际正在显示**的朝向继续，不会跳变。

**模型：** ISS 系列（ISS / ZARYA / CSS / TIANGONG / TIANHE / MIR）
加载烘焙好的二进制网格；HST / HUBBLE 使用圆柱模型；其余回退为矢量图形。
网格文件格式见[数据源与 SGP4](Data-and-SGP4-zh)。

### 🗺 世界地图

2D 等距圆柱投影地图：海洋底色、经纬网（经线 ±180/±120/±60/0，
纬线 ±60/±30/0，均带标注，赤道加粗）、Natural Earth 110m 海岸线，
以及选中卫星的标记与 `名称 / 高度` 标签。**无交互** —— 静态渲染，无相机状态。

### 🛰 地面轨迹

选中卫星从**过去 45 分钟到未来 90 分钟**的地面轨迹，每 2 分钟采样一次；
当前位置用圆点加白色圆环标出，并标注名称与高度。
跨越 ±180° 经线的段会被跳过，而不是画一条横穿地图的线。
经纬网复用世界地图的辅助函数。未选择卫星时窗格显示
`Select a satellite in the sidebar`。

### 📋 详情

选中卫星的实时轨道要素：NORAD 编号、分组、纬度、经度、高度（km）、
速度（km/s，由 vis-viva 公式导出，µ = 398 600.4418，R⊕ = 6371 km）、
TLE 历元，以及折叠面板下的原始 TLE 两行。
若 TLE 无法推演，则以红字说明，而不是显示过期数值。

> 注意：详情窗格读取的是 `Utc::now()`，**不是**加速后的仿真时钟 ——
> 因此即使地球以 ×1000 运行，它报告的仍是卫星**真实**的当前状态。

### 📃 目录

与侧栏相同的列表，以窗格形式呈现。

## 实际可达的视图

读代码时请注意：窗格标题栏的切换按钮只提供 **`3D` 与 `2D`**，
即 `Globe3D` 与 `WorldMap`。`GroundTrack` 与 `Detail` 已完整实现，
只要把窗格的 view 设为它们就会正常渲染，但**运行中的 UI 没有任何控件能设置它**。
它们可通过代码路径到达（并有测试覆盖）；README 所说的「四种视图」指的是
**已实现的集合**，而不是工具栏上的四个按钮。

侧栏始终使用「目录」渲染器，与窗格视图无关。

## 分屏布局

工具栏的 `Layout:` 控件在工作区之间切换：

| 标签 | 窗格数 | 排布 |
|---|---|---|
| `1` | 1 | 单个全区域视口 |
| `2H` | 2 | 左右并排 |
| `2V` | 2 | 上下堆叠 |
| `4` | 4 | 2×2 四象限，顺序为左上、右上、左下、右下 |

窗格矩形由 `Layout::panes()` 在归一化 `[0,1]²` 空间计算，再缩放到可用区域，
因此布局与分辨率无关。

切换布局时按**索引**保留窗格 —— `1 → 4` 切换后 0 号窗格的卫星与相机仍然保留。
有一处刻意的例外：0 号窗格会从 `WorldMap` 强制回到 `Globe3D`，
活动窗格重置为 0。

## 窗格边框与焦点

每个窗格带一条 18 px 标题栏显示选中卫星名，外加一圈边框：
活动窗格为 2 px 蓝色，非活动为 1 px 灰色。点击窗格任意处即激活该窗格 ——
侧栏点击与右键「加入第 N 个窗口」都作用于活动窗格。

标题栏还包含时区快捷按钮（`Beijing` / `DC`）与 `3D` / `2D` 视图切换。

## 瞬时提示

从行右键菜单重定向窗格时，该窗格左上角会闪现一段白色
`Added <名称> to Window N` 提示。淡入 0.45 秒、保持 2.4 秒、淡出 0.45 秒后消失 ——
合计 3.3 秒。同一时刻只存在一条提示，新提示会替换旧提示。
左键聚焦与复制操作**刻意不弹**提示。
