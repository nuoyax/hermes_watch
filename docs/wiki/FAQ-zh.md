# 常见问题

## 什么都加载不出来 —— 目录为空或几乎没有数据

当前网络无法访问 Celestrak。工具栏会显示橙色 `⚠` 与错误信息，悬停可查看。

处理：设置 HTTP(S) 代理。可在工具栏 `⚙ Settings` 中填写后按 `✔ Apply & Refresh`，
或用环境变量：

```sh
SAT_PROXY=http://127.0.0.1:7890 cargo run --release
```

UI 中的值优先于 `SAT_PROXY`；两者都在下次刷新生效。见[安装与运行](Installation-zh)。

## 收到 Celestrak 的 HTTP 403

裸 HTTP 客户端会被拒。应用本身已带浏览器风格 `User-Agent`，
因此出现 403 通常说明是网络链路本身被拒（企业封锁或地域限制），
而非请求头问题 —— 请走代理。

## 地球/地图空白，但侧栏有卫星

TLE 能加载但无法推演 —— 通常是历元过旧。等待下次 2 小时自动刷新，
或选择历元较新的卫星。无法推演的卫星在侧栏列表中显示为**红色**，
因此在选择前就能看出来。

详情窗格对同一原因会以红字显示 `Propagation failed for this TLE`。

## Linux 构建失败

安装 X11/Wayland 开发库。eframe 同时启用了 `x11` 与 `wayland` feature。

## 界面感觉卡顿

用 `RUST_LOG=info` 看日志 —— 帧循环对超过 50 ms 的单帧会打印 `slow frame` 警告。
常见原因：目录异常庞大，或某个窗格的地球网格在逐帧重建
（正常情况下只应在拖拽或相机缓动进行时发生）。

## 为什么某些卫星归到了「其他」分组？

分组归属由**数据来源**决定，不从名称解析。来自 `active` 分组的所有目标都归入 `Other`。
见[数据源与 SGP4](Data-and-SGP4-zh)。

## 为什么「军用」和「碎片」始终显示 (0)？

配置的六个源都不提供这两类数据。它们保留下拉框中是为了展示完整分组集合，
在新增数据源之前会一直为空。

## 为什么详情窗格显示的时间与时钟不同？

这是刻意的。详情窗格读取真实 UTC（`Utc::now()`），而地球运行在加速的仿真时钟上。
因此在 ×1000 时，地球上的轨道飞速推进，而详情仍报告卫星真实的当前状态。

## 卫星数量一直在涨 / 卫星出现重复

已知行为：每次成功刷新都**追加**进目录，不做去重，
因此长时间运行的会话会累积重复项。重启进程会重建目录。
见[数据源与 SGP4](Data-and-SGP4-zh)。

## 窗格只能在 3D 和 2D 之间切换 —— 地面轨迹和详情在哪？

它们已实现且能正确渲染，但窗格标题栏的切换只提供 `3D` 与 `2D`。
目前没有任何 UI 控件能把窗格设为 `GroundTrack` 或 `Detail`。见[视图说明](Views-zh)。

## 贴图和网格文件在哪？

在编译期通过 `include_bytes!` 嵌入二进制。运行时没有需要随可执行文件分发的资源目录。
仓库中有两个文件 —— `land110.json` 与 `stars_bright.json` —— 目前源码未引用。

## 能离线使用吗？

界面与渲染可以，但目录在启动时需要 Celestrak ——
本地没有任何 TLE 磁盘缓存。
